# Radar Sport & Actus

App personnelle (PWA) : agenda des grands rendez-vous sportifs et culturels, actus et articles de fond, en français et en arabe.

- `index.html` : l'app
- `data.json` : les données, mises à jour chaque matin
- `sw.js`, `manifest.webmanifest`, `icons/` : installation sur l'iPhone et mode hors ligne
- `netlify.toml` : réglages Netlify (aucune étape de build)
